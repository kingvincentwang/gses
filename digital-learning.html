2

部署前準備

先準備好帳號、專案與資料來源
  1. 一個負責部署的 Google 帳號。
  2. 一份 Google 試算表。
  3. 一個 Firebase 專案。
  4. 完整系統程式檔案。
  5. 若要指定 PDF 存放位置，預先建立兩個 Google Drive 資料夾。
部署帳號建議長期保留：需具備系統試算表編輯權、MDM 來源試算表檢視權、兩個佐證資料夾編輯權，以及 Firebase 專案管理權。
3

建立 Firebase 專案與 Google 登入

Firebase 僅作身分驗證
3.1 建立 Firebase 專案
3.2 建立 Web App
3.3 啟用 Google 登入
3.4 Firestore 非必要

Firebase Web App 需取得四個值

const firebaseConfig = {
  apiKey: "...",
  authDomain: "專案ID.firebaseapp.com",
  projectId: "...",
  appId: "..."
};
  • Authentication → Sign-in method → Google → 啟用
  • 桌機優先使用 Popup，受阻時可改 Redirect
  • 本系統不需 Firebase Hosting
  • 本系統不需建立 Firestore

5

設定 Apps Script 指令碼屬性

專案設定 → 指令碼屬性

Firebase 必填屬性

屬性名稱內容
FIREBASE_API_KEYFirebase Web App apiKey
FIREBASE_AUTH_DOMAINFirebase authDomain
FIREBASE_PROJECT_IDFirebase projectId
FIREBASE_APP_IDFirebase appId

試算表 / PDF 屬性

屬性用途
SPREADSHEET_ID主要試算表 ID（綁定式 GAS 可省略）
MDM_SPREADSHEET_IDMDM 來源試算表 ID
SOFTWARE_EVIDENCE_FOLDER_ID軟體效益佐證 PDF
MONITORING_EVIDENCE_FOLDER_ID管考觀議課佐證 PDF
6

第一次初始化 Google Sheets

執行 initializeSystem()
  1. 在 Apps Script 函式下拉選單選擇 initializeSystem。
  2. 按「執行」。
  3. 第一次執行完成 Google 授權。
  4. 等待執行完成。
  5. 回到 Google 試算表重新整理。
