# 115年度數位素養宣導活動｜動漫宣導影片

由「小數」（動漫女孩）與「位位」（機器貓）主持的數位素養宣導影片，約 1 分 47 秒。

- **digital-literacy.mp4**：成品影片（1280×720，含旁白、字幕、背景音樂）
- **index.html**：網頁版播放器（可直接在瀏覽器播放，或嵌入學校網站）

## 內容（9 個場景）
開場 → 什麼是數位素養 → 學生篇 → 教師篇 → 家長篇 → 宣導場合 → 宣導對象 → 繳交期限（115/10/15）與表單 QR Code → 結尾

## 更換旁白或台詞
1. 把音檔放進 `audio/`，檔名為 `s場景_句子.mp3`（例如 `s03_02.mp3`）。
2. 台詞文字在 `index.html` 的 `SCENES` 陣列裡修改。
3. 重新產生：
   ```bash
   python3 build.py          # 讀取音檔長度與嘴型音量 → clips.js、QR Code、背景音樂
   node render.js            # 輸出 digital-literacy.mp4（需要 Playwright + ffmpeg）
   ```
畫面停留時間會依音檔長度自動調整；沒有音檔的句子會依字數估算時間，只顯示字幕。
